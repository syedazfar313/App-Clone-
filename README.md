# 📱 App Clone Repository

Welcome to the **App Clone** repository! This project is a collection of **fully functional clones of popular applications** developed using Python (Flask), HTML/CSS, and SQLite. Each clone is designed for academic, learning, or demonstration purposes — particularly useful for semester projects, cybersecurity practice, or UI/UX learning.

---

## ✅ Current Clones Included

### 1. 📸 Instagram Clone (Flask App)
A simplified clone of Instagram with basic features:
- 👤 User Authentication (Login/Register)
- 🖼️ Photo Upload with Captions
- ❤️ Like and 💬 Comment on Posts
- 👥 Profile Page to View Posts
- 🔐 Session Management

---

## 🛠️ Technologies Used

- **Flask** – Backend Web Framework
- **SQLite** – Lightweight DB for local storage
- **HTML/CSS + Bootstrap** – Frontend & Styling
- **Jinja2** – Templating Engine for Flask
